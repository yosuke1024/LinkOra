# Travel statistics（Wave 3: travel signal）

**判定: 候補確定・実装は M5** — 実装時に採用ソースごとの個別確認ファイルを追加する。

## 求めるデータ

`source 国 -> target 国` の旅行需要。合法的に利用可能な**公的集計統計**のみを使う（航空予約データ等の商用データは対象外）。

- 粒度: 月次（最低でも年次）、出発国（国籍または居住国）別の入国者数
- 用途: travel signal（Voigie との接続点でもある）

## 候補ソース

### 国際機関

| ソース | 内容 | 制約 |
|---|---|---|
| UN Tourism (旧 UNWTO) | 各国の inbound arrivals（国籍/居住国別） | 詳細データは有償購読の範囲が広い。無償部分の利用条件を実装時に確認 |

### 各国の公的統計（target 国側の inbound 統計）

対象 10 か国それぞれの受入統計が `X -> target` の需要を与える。主要候補:

| Target | ソース | 備考 |
|---|---|---|
| JP | JNTO 訪日外客統計 | 月次・国籍別。無償公開。政府標準利用規約（出典明記で利用可）を実装時に確認 |
| KR | 韓国観光公社 (KTO) 統計 | 月次・国籍別 |
| TH | タイ観光・スポーツ省 | 月次・国籍別 |
| ID | BPS (インドネシア中央統計庁) | 月次・国籍別 |
| VN | ベトナム統計総局 / 観光総局 | 月次・国籍別 |
| SG | Singapore Tourism Board | 月次・居住国別 |
| FR | INSEE / DGE | 集計粒度に注意 |
| DE | Destatis (宿泊統計の居住国別) | 入国統計でなく宿泊統計 |
| US | NTTO (I-94 到着データ) | 月次・国籍別 |
| IN | Ministry of Tourism (India) | 月次・国籍別 |

## 実装方針（M5 で確定）

- 国ごとに形式・言語・更新頻度が異なるため、**target 国単位のサブ provider**（例: `travel-jnto`）として実装し、共通の travel signal に正規化する。
- 全 10 か国を一度に揃えず、規約確認が済んだ国から段階的に追加する（signal の欠落は confidence に反映される設計）。
- 各国のオープンデータ利用規約（出典明記の要否・商用利用・再配布条件）を、実装前に `travel-<source>.md` として個別に記録する。
