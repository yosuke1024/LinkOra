# Google Trends（Wave 2: search signal）

**判定: 保留（HOLD）** — 現時点でパイプラインに追加しない。

## 状況

- Google Trends の一般公開データはウェブ UI と CSV エクスポートが中心で、**全機能を対象とした一般公開の公式 API は提供されていない**。
- Google は公式の Trends API（alpha）を限定テスターに提供開始している（2025 年発表）。一般提供の時期・条件は未確定。
- pytrends 等の非公式ライブラリは内部エンドポイントへの依存であり、Google の利用規約に抵触するリスクがある。企画（pixapps_strategy#25）の非目標「データソースの規約に反する取得」に該当するため**採用しない**。

## 保留の条件と再評価トリガー

1. 公式 Trends API への正式なアクセスを取得できた場合
   - その際、商用利用・保存・derived data 提供の条件をこのファイルに追記してから実装する
2. 検索関心の代替ソース（例: 各検索エンジンの公式提供データ、規約上問題のない集計データ）が見つかった場合
